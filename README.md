# 物件概要ワークスペース

公開URL：https://enjin-7370.github.io/shimizu-property-excel/

公開版：v0.5.0-browser。トップの簡易パスワード入口付き。APIは未接続です。

1物件の資料またはZIPを追加すると、読取と編集用Excelの作成が自動で始まります。結果欄には不足・不一致の理由と、自由記載の指摘欄がひとつあります。

- GitHub Pages向け。専用サーバー、データベース、GCP契約は不要。
- 入力資料・入力内容・Excelはメモリ内だけで処理。外部へのアップロード、自動保存、アクセス解析はありません。
- 任意の「途中データを保存」は利用者の端末へのダウンロードです。
- PDFのテキスト、XLSX、CSV、TXT/MDからの定型項目抽出、レントロールの列指定・明細確認・集計、Excel出力に対応。
- 画像と単一画像のスキャンPDFは端末上で日本語OCR（Tesseract.js 6.0.1）を実行します。1資料4頁、1回8頁までで、未読の頁は明示します。OCR結果と項目の抽出精度は原資料に依存します。外部AIは未接続です。
- すぐ特定できる「物件名は「…」に訂正」「価格：…万円」などの指摘は値に反映してExcelを更新。その他の指摘は要確認履歴へ残し、途中データと一緒に手元へ保存できます。
- レントロールは同名シートを優先し、明細・区画数・年間額の明らかな矛盾を表示。現況・満室の別、税区分、期間、明細と合計が確かめられる収入を採用します。
- トップに簡易パスワード入口があります。解除情報やパスワードは保存しません。再読み込みすると入口へ戻ります。これは公開ソースへのアクセスを制限するサーバー認証ではありません。利用者ごとの作業内容は共有されません。
- 初回は固定版Pyodide 0.29.3とPillow 11.3.0をjsDelivrから読み込みます。資料や入力値をCDNへ送信しません。
- 公開物はアプリ、空の帳票、ライブラリのみ。実物件資料、APIキー、会社認証情報は含めません。

## 公開

GitHub Settings → Pages → Deploy from a branch → `main` / `docs`。
無料Pagesではこのリポジトリも公開されます。2026-11-10に所有者がコード・空帳票の一般公開を承認しました。

## 構成と更新

`src/`は既存v0.3.0で検証した抽出・帳票処理と元画面、`docs/`が公開対象。Python処理はWeb Worker内のPyodideで実行します。実行コードを資料から組み立てません。

Python 3.12以降で`python build.py`を実行すると、ブラウザ用の設定・アーカイブと照合値を更新します。ビルドに外部ライブラリは不要です。PDFライブラリpypdf 5.9.0のPythonソースとライセンスは`vendor/`に同梱しています。

生成Excelは原本の105結合範囲を保持し、既存修正版の会社欄用4結合を含む109範囲・36入力セル・7計算式を維持します。別物件リンクはありません。PDFの自動出力は行いません。

## 検証と限界

`tests/VALIDATION.md`を参照。ブラウザ検査はローカルで静的ファイルを配信した検査です。公開URL・実AI・本人の実Excel端末での確認とは区別します。APIキーは公開リポジトリやブラウザコードへ書き込まないでください。

## 復旧

変更前のcommitへ戻してPagesを再配信します。公開自体の停止はSettings → Pages → Unpublish site。利用者がダウンロードしたファイルをアプリから消すことはできません。
